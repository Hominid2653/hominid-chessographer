# Chessographer

React, Vite, Tailwind CSS, and Radix UI, organized as a component architecture.

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — typecheck and production build
- `npm run lint` — oxlint
- `npm run preview` — preview the production build

## Layout

- `src/app` — application root and providers
- `src/components/ui` — Radix-backed primitives
- `src/components/layout` — shells and page chrome
- `src/features` — feature modules
- `src/lib` — shared helpers
- `src/styles` — Tailwind and design tokens
